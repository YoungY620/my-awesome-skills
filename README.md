# my-awesome-skills

A curated collection of reusable skills for AI coding agents. Each skill lives in its own directory under `skills/` and can be used independently.

## Skills

- **[sniff-check](skills/sniff-check/)** — MR review and merge-check standard: indivisible small MRs, contract and configuration hygiene, credential separation, and verification that proves the claimed behavior actually happened, with `create` / `merge` / `review` / `learn` workflows.
- **[course-textbook-builder](skills/course-textbook-builder/)** — Turn a course's full materials (slides, lecture videos/audio, transcripts, readings, assignments and solutions) into a high-density online textbook in the style of textbook.cs161.org: mdBook, bilingual, deployed to GitHub Pages, with real-render verification.
