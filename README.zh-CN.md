# my-awesome-skills

一组可复用的 AI 编程助手技能合集。每个技能独立存放在 `skills/` 下的目录中，可单独使用。

## 技能列表

- **[sniff-check](skills/sniff-check/)** — 方案、PR/MR 评审与偏好学习标准：独立交叉验证、小变更、有依据的复杂度、凭证边界和可观察行为验证，包含 plan / create / merge / review / learn 流程。
- **[course-textbook-builder](skills/course-textbook-builder/)** — 把一门课的全套材料（课件 PDF、讲课视频/音频、字幕转录、每讲 readings、作业与解答）转换成 textbook.cs161.org 风格的可精读在线教材：mdBook、可双语切换、部署到 GitHub Pages，并以真实渲染做核验。
